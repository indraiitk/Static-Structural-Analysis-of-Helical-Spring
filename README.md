Spring Design and Energy Storage Analysis

## Project Overview

This project presents the static structural analysis of a helical spring using ANSYS Workbench. The analysis evaluates the structural response of the spring under the applied loading conditions.

## Objectives

- Analyze the structural behavior of a helical spring.
- Determine the equivalent (von-Mises) stress.
- Determine the equivalent elastic strain.
- Evaluate total deformation.
- Calculate strain energy.
- Assess the response of the spring using finite element analysis.

## Software Used

- ANSYS Workbench 2026 R1 Student
- CAD modeling software
- STEP file for geometry

## Analysis Results

The following results were obtained from the ANSYS static structural analysis:

| Result | Maximum Value |
|---|---:|
| Equivalent Elastic Strain | 1.7185 m/m |
| Strain Energy | 106.24 J |
| Equivalent (von-Mises) Stress | 3.4358 × 10¹¹ Pa |
| Total Deformation | 5.0211 m |

## Results

### Equivalent Elastic Strain
The equivalent elastic strain distribution was obtained throughout the spring.

### Equivalent Stress
The von-Mises stress distribution was evaluated to study the stress developed in the spring.

### Total Deformation
The total deformation of the spring was obtained under the applied loading condition.

### Strain Energy
The strain energy stored in the spring was evaluated from the static structural analysis.
